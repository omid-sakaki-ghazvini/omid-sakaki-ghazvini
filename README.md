## 🚀 Featured Projects

### 🧮 Accounting Showcase — Full-Stack Accounting System

A production-ready, bilingual (Persian/English) accounting system demonstrating Clean Architecture with .NET 8 and modern React 19.

**Highlights:**
- 🏗️ **Backend:** ASP.NET Core 8, EF Core, Minimal API, Docker
- ⚛️ **Frontend:** React 19, TypeScript, Tailwind CSS, shadcn/ui
- 💼 **Domain:** Chart of accounts, Invoices, Double-entry Journal entries
- 📊 **Double-entry validation** (Debit = Credit)
- 🌐 **RTL Persian UI** with Vazirmatn font
- 📦 **25 standard accounts** with seed data
- 🐳 **Docker-ready**

**Tech Stack:** `C#` `ASP.NET Core` `EF Core` `Docker` `React` `TypeScript` `Tailwind` `shadcn/ui` `Vite`
